# Cuestionario de Git — Teoría y práctica

**Consigna:** Respondé las siguientes 10 preguntas. En los ejercicios prácticos, escribí los comandos completos que utilizarías en la terminal. Justificá tus respuestas cuando sea necesario.

### 1. Teoría
¿Qué es Git y para qué se utiliza? Explicá con tus palabras qué problema resuelve en el desarrollo de software.

### 2. Teoría
¿Cuál es la diferencia entre los siguientes comandos?

- `git add`
- `git commit`
- `git push`

Explicá qué hace cada uno y en qué orden se utilizan habitualmente.

### 3. Práctica
Creaste una carpeta para un proyecto nuevo y querés comenzar a utilizar Git.

Escribí el comando que utilizarías para inicializar un repositorio en esa carpeta.

### 4. Práctica
Modificaste los archivos `index.html` y `styles.css`, pero querés guardar únicamente los cambios de `index.html` en el próximo commit.

Escribí los comandos necesarios para preparar ese archivo y registrar los cambios con el mensaje `Actualiza página principal`.

### 5. Teoría
¿Cuál es la diferencia entre un repositorio local y un repositorio remoto? Mencioná un ejemplo de plataforma donde se puedan alojar repositorios remotos.

### 6. Práctica
Estás trabajando en la rama `main` y necesitás desarrollar una nueva funcionalidad llamada `login`.

Escribí el comando para crear esa rama y cambiarte a ella sin modificar directamente `main`.

### 7. Teoría
¿Qué es una rama (*branch*) en Git y qué ventajas tiene trabajar con ramas diferentes dentro de un mismo proyecto?

### 8. Práctica
Un compañero subió cambios al repositorio remoto y necesitás incorporarlos a tu repositorio local.

¿Qué comando utilizarías habitualmente para descargar e integrar esos cambios? Explicá brevemente qué hace.

### 9. Práctica
Estás trabajando en la rama `main` y terminaste de desarrollar una funcionalidad en la rama `registro-usuarios`.

Escribí los comandos necesarios para integrar los cambios de `registro-usuarios` en `main`.

### 10. Teoría y práctica
Ejecutaste el comando `git status` y Git te informa que tenés archivos modificados que todavía no fueron preparados para un commit.

a) ¿Para qué sirve el comando `git status`?

b) ¿Qué comando utilizarías para preparar todos los cambios del directorio actual?

c) ¿Qué comando utilizarías después para guardar esos cambios en el historial con el mensaje `Corrige errores del proyecto`?
